# DCU-2026-07-25-04 — Update notification and distribution

The update client calls GitHub's latest-release endpoint for a public
repository without embedding credentials. It sends `If-None-Match`, handles
`304`, treats rate limits and malformed releases as recoverable errors, strips
an optional `v` from tags, compares semantic versions, and remembers an ignored
version.

The notification never claims installation succeeded. Its action routes to:

- Play in-app/store update for a Play-distributed Android build;
- a signed GitHub APK/release page for an explicitly sideloaded Android build;
- the Mac App Store or a Developer ID-signed/notarized package;
- the Microsoft Store or a signed MSIX/installer.

Publishing and installing remain blocked until the repository, application
identities, certificates, store channels, and signing secrets are configured.
