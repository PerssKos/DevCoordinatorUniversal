# DCU-2026-07-25-01 — Cross-platform foundation

## Evidence

- Source baseline: `holyglory/DevCoordinator` at
  `292ee3a556a1f65342f484f9cb1e8304dedd811f`.
- Flutter 3.44.8 / Dart 3.12.2 stable were used to generate the platform
  runners.
- Flutter officially supports installed Android, macOS, and Windows apps and
  provides Material and Cupertino widget libraries.
- Dart Pub workspaces provide one dependency resolution and one lockfile for
  the application and internal packages.

## Alternatives and consequences

- Compose Multiplatform: strong Android/Kotlin fit, but JVM desktop packaging
  and no first-party Cupertino component suite.
- React Native: native-component model, but Windows and macOS are separate
  out-of-tree projects with additional compatibility lifecycle.
- Tauri: good for a web-first shell, but the user requested a full adaptive
  installed client rather than a WebView wrapper.

Flutter is BSD-3-Clause and has no framework fee. Platform distribution still
requires separate signing, store accounts, and target-host build tools.
