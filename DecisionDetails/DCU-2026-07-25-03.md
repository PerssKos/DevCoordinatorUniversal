# DCU-2026-07-25-03 — Extensible appearance

The One UI-inspired pack follows large-title hierarchy, generous rounded
surfaces, bottom-reachable primary navigation on phones, and responsive
desktop/foldable layouts. It uses original colors and geometry and does not
ship Samsung branding, icons, or fonts.

The Cupertino pack uses Flutter's first-party Cupertino behavior where it
materially affects interaction. It does not embed Apple's San Francisco font
on Android or Windows.

Every feature consumes the same semantic status, spacing, typography, motion,
surface, and action roles. Brightness is resolved after style selection, so
each style supports system, light, and dark modes.
